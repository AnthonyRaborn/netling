SPRITE GALLERY

Spoilers: shows every form, secret and earned item. Development only; not deployed. Open it through npm run serve (http://localhost:5174/gallery.html): opening the file directly does not work. Everything is drawn by the game's own code (renderLCD and friends), so what you see is what ships. Review plan: docs/SPRITE_REVIEW_PLAN.md. Pink outlines mark a wearable that a check (tools/lib/sprite-checks.mjs) thinks blends into the pet: half or more of its pixels look like what is under or beside them. Hover a cell for the reason. Candidates only; node tools/sprite-audit.mjs lists them all.
