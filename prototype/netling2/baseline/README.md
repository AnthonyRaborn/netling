# Netling 2.0 simulator baseline

Status: scripted bots only. Nothing here was playtested, run on a device or checked with `npm run smoke`. Every figure is a model, not a measurement of people; read the limits in `docs/netling2-prototypes/README.md` before quoting one.

This directory re-runs the whole simulator suite in `prototype/netling2/sim/` at 1000 lives and keeps every output in `results/`, so later rule changes can be compared with one set of numbers. The first run was taken 2026-10-08 on branch `ccr-d71db475-tnfy9b` (rules code at `956cbce`). The current reference is **the now set** (below), not that first run.

The long result tables and the per-follow-up narrative were moved out of this file. The byte-identical full text is `../../../docs/archive/netling2/BASELINE_README_FULL.md`; pointers below name its section headings.

## Files

Scripts are listed under Commands. `summary-balance.md` is generated by `summarize.mjs` (37 archetypes by 16 columns per configuration, and each egg against core). `results/` holds one file per job (`.json` where the tool supports `JSON=1`, else `.txt`) and `_run.log` (start, finish and duration of every job).

## Commands

Run from the repo root. All jobs run with `TZ=UTC`.

```bash
node prototype/netling2/baseline/run-all.mjs [jobFilter] [--jobs=4] [--lives=1000] [--force] [--smoke]
```

- `jobFilter` is a substring of a job name (`balance`, `clinic`, `now-`, `inherit-`, `now-balance-wetware`); no filter runs everything.
- Resumable: a job whose output exists is skipped, and an output is written only after a clean exit. `--force` re-runs the matching jobs. `--smoke` runs tiny counts into `_smoke/` to check that every job starts.
- **Never import `run-all.mjs`; importing it runs it.** (Same for `gap-reruns.mjs` and the `rogue-*.mjs` runners.)
- Every job gets `INHERIT='{"fullLife":false}'` unless it sets its own, so jobs from before the full-life inheritance rule still reproduce.
- `node prototype/netling2/baseline/summarize.mjs` rewrites `summary-balance.md` (needs the four `balance-*.json` of the first set).
- `node prototype/netling2/baseline/compare-now.mjs [name filter] [--all]` compares `results/now-*` with the job it repeats (`balance-decided-<egg>` for `now-balance-<egg>`). Thresholds: full life and other shares 2 points, other numbers 15% and 0.1. `--all` lists every changed text line.
- `node prototype/netling2/baseline/gap-reruns.mjs [filter] [--jobs=4] [--force]`: 55 jobs (`bugs-*`, `hardened-*`, `pressure-*`, `fix-*` and more), resumable, about 24 CPU minutes (8 minutes at 3 jobs), output `results/gaps/`.
- Rogue scripts (resumable; each header comment gives its arguments): `rogue-hide-lock.mjs` (HIDE lockout grid, draft 7.2), `rogue-stage2.mjs` (whole lives with the hunt in runs), `rogue-dodge.mjs` (Dodge levers, 7.4), `rogue-deep-levers.mjs` (Deep map levers, 7.4 and 9.7), `rogue-lineage.mjs [lineages=200] [rogueLives=10] [--jobs=4] [jobFilter]` (Rogue lineages). Printers: `rogue-hide-lock-summary.mjs`, `rogue-stage1-summary.mjs`, `rogue-stage2-summary.mjs`, `rogue-lineage-summary.mjs`, `rogue-levers-summary.mjs`.
- `../sim/act-calibrate.mjs` needs a bar and a line as arguments; it is a calibration helper, not a sweep, and is not in the runner.

## Configurations

Defined in `run-all.mjs` (`CONFIG`). The pressure numbers are the ones `clinic-final.mjs`, `grace-sweep.mjs` and `hint-sweep.mjs` use for the final design in `docs/archive/netling2/EGG_PRESSURES.md`.

| Name | Switches | Used by |
|---|---|---|
| core | none: the 2.0 core rules only (Standing, temper, bugs, the clinic, the soft push); pressures, netrun rules and perks off | `balance-core` |
| full-iron / full-program / full-wetware | `NR2=all PERKS=1` plus that egg's final pressure design (Iron: wear, Overclock benefits tripled; Program: Overdrive; Wetware: Overlink with its brake), owner multiplier 3, hold 3 awake hours | `balance-full-<egg>`, `runcost-<egg>`, `egg-anomaly-<egg>` |
| rules | `NR2=all PERKS=1`, no pressure; sweeps that model a pressure set their own | every other first-set sweep |
| decided-`<egg>` | stage care as stageA (7 hour baby at x2.4 drain, the rest call), Standing gain 2, the bug fix rule and cost 5, the break | `balance-decided-<egg>` |
| now-`<egg>` | decided-`<egg>` plus `OVERUSE` and, through `BRAKE`'s defaults, the break on every state and the strain trigger at 80 | the `now-*` jobs |
| now-rules | now-`<egg>` with no egg pressure, for sweeps that set their own | the `now-*` life and netrun sweeps |

`runcost-sweep.mjs` and `egg-anomaly-sweep.mjs` default to a minimal Program and Wetware pressure; the runner passes the full final design, so their tables do not compare with older tables in the notes.

Sample sizes: 1000 lives per archetype over 37 archetypes (the docs say 36); lineage 200 lineages of 15, 20 and 40 lives; challenge 2000 runs, Foresight and egg anomaly 3000. Noise at 1000 lives is about 1 point on a full-life rate near 90%.

## The now set (current reference)

The first set ("the before", 2026-10-08 rules) is `balance-core`, `balance-full-<egg>` and the unprefixed sweeps. **The now set** is every sweep re-run under the rules decided through 2026-10-09 (jobs named `now-*`: configuration `now-<egg>` or `now-rules`; filter `now-`; 36 jobs, 1000 lives, lineages 200). Use `results/now-*` as the reference for current rules; use the unprefixed outputs only for the before. `now-balance-<egg>` pairs with `balance-decided-<egg>`. The rejected act and band designs were not re-run. The now set did not re-run `results/followup/`; each follow-up states its own settings.

Layered on the now set: `inherit-lineage-{attentive,daredevil,casual}` (filter `inherit-`; full-life inheritance rule; 270, 365, 660 s), `results/gaps/` and its `strain5-*` files (Wetware jobs re-run at the decided strain add of 5).

Rule: when a rule changes, keep the earlier results under their own names and write the re-run under a new name (a new prefix or a `superseded/` folder for outputs that are wrong), so older tables stay traceable.

## Operational notes

- The container restarts when idle and kills background jobs (the first run was killed twice). Start long runs with `setsid nohup node ... &` (advice from `docs/archive/netling2/BASELINE_AND_STAGE_CARE.md`, line 98), and re-run the same command to continue. `_run.log` times include contention; results do not.
- Long jobs: `pressure-*` about 16 minutes each, `clinic-final` about 30, `iron` sweeps about 22. Use `--jobs=3` or `4`.
- Not run: `npm run smoke`, any device check, any playtest.
